# Landing page — Pure Glow Cosmetics

Página web estática, responsiva y en español para presentar el Aceite Corporal Nutritivo.

## Estructura

- `index.html`: toda la página, con CSS incluido.
- `assets/logo.png`: logotipo proporcionado.
- `assets/mockup.png`: mockup proporcionado.

## Publicarla en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo, `pure-glow`).
2. Sube `index.html` y la carpeta `assets` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main`, carpeta `/ (root)` y haz clic en **Save**.
6. Abre la dirección de GitHub Pages indicada por GitHub cuando se publique.

Para verla en tu computadora, abre `index.html` en el navegador.

La fuente Montserrat se obtiene de Google Fonts (necesita conexión a internet); de lo contrario, se muestra Arial.
